# 단축키

v0.5.2에 키맵을 lazydocker, vim 관례에 맞춰 다시 짰다. 상태줄 힌트, `?` 도움말, `squad --help`, README 표가 모두 같은 키를 가리켜야 하고, `hints_and_help_stay_in_sync` 테스트가 어긋남을 잡는다.

## 매니저 모드

| 동작 | 키 |
|---|---|
| 열기(정지 상태면 시작 후 포커스) | `Enter`, 클릭 |
| 이동 | `j`/`k`, `↑`/`↓`, `1`–`9`, `Home`/`End` |
| 필터 | `/` (`Enter` 유지, `Esc` 해제. 매니저에서도 `Esc`가 유지 중인 필터를 해제) |
| 추가 | `a` |
| 한 줄 전송 | `m` |
| 중지 | `s` (확인창) |
| 재시작 | `r` |
| 삭제 | `d` 또는 `Delete` (확인창. 실행 중이면 먼저 종료. 파일은 건드리지 않음) |
| 전체 시작 | `S` |
| 스크롤 | `PgUp`/`PgDn`, 마우스 휠 |
| 도움말 | `?` |
| 종료 | `q`, `Ctrl+C` (세션이 있으면 확인창) |

## 터미널(포커스) 모드

- `Esc`: 매니저로 복귀.
- `Ctrl+G` 다음 `g` 또는 `Esc`: 세션에 `Ctrl+G` 또는 `Esc`를 그대로 전달. 다른 키는 접두사만 취소.
- 스크롤은 `Shift+PgUp`/`Shift+PgDn`, 라이브로 복귀는 `Shift+End` 또는 입력.
- 마우스: 사이드바 행 클릭은 선택, 실행 중인 터미널 영역 클릭은 포커스.

## 바뀐 이력

| 동작 | 이전 | 현재 |
|---|---|---|
| 필터 | `f` | `/` |
| 한 줄 전송 | `/` | `m` |
| 중지 | `x` (v0.5.0까지 `Delete`도) | `s` |
| 전체 시작 | `s` | `S` |
| 삭제 | `Delete` | `d`, `Delete` |
| 이동 | `n`/`p` | `j`/`k` |

이전 키 `x`, `n`, `p`는 손에 익은 동작이라 계속 동작하지만 도움말과 힌트에는 나오지 않는다.

## 결정과 주의

- `Delete`는 v0.5.0까지 중지 키였다가 삭제로 바뀌었다. 습관적으로 `Delete`로 중지하면 프로젝트가 사라지므로 중지는 `s`를 쓴다(삭제는 확인창 후 `y`).
- `S`(전체 시작)는 대문자라 Caps Lock이 켜져 있으면 `s`(중지) 자리에서 전체 시작이 실행된다. 되돌릴 수 없는 동작은 아니다.
- 입력, 필터, 추가 폼의 한 줄 편집은 `←` `→` `Home` `End` `Delete`를 지원한다.
