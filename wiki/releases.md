# 릴리스 이력

버전별 변경. 최신이 위. 행은 `tools\release.ps1`이 추가한다.

- v0.15.30~v0.15.33은 태그만 있고 GitHub Release가 없다. macOS 빌드가 컴파일에 실패해 publish 잡이 아무것도 올리지 않았다(모든 플랫폼이 성공해야 올림). v0.15.34에서 고쳤고, v0.15.35부터 릴리스 스크립트가 macOS 타깃 clippy로 태그 전에 잡는다.
- v0.15.35~v0.15.37도 GitHub Release가 없다. macOS 테스트 `quick_reply_opens_via_badge_and_cycles_waiting_agents`가 멈춰 aarch64 빌드가 끝나지 않았고(v0.15.32 무렵부터 간헐적, v0.15.34 CI도 같은 이유로 취소됨) 실행을 취소했다. v0.15.38에서 고침: 테스트가 실제 셸에 `yes`를 보내 출력이 폭주하고, 세션 정리 때 쓰기 핸들의 EOF 쓰기가 비워지지 않는 pty를 기다린 것으로 본다(macOS에서 직접 재현은 못 함). 잡마다 시간 제한도 걸었다.
- v0.5.1~v0.5.4(2026-11-06)의 배포 확인 과정은 [log.md](log.md)에 있다.
