# 코드 리뷰 결과와 처리 현황

2026-11-06에 v0.5.0 코드를 전체 읽고 정리한 항목이다. 상태: **고침**(릴리스 버전), **보류**(의도적으로 안 함), **안 함**(해당 없음 또는 불가).

## 버그와 위험

| # | 항목 | 상태 | 비고 |
|---|---|---|---|
| 1 | `install.ps1`이 프로세스 `$env:Path`(머신 + 사용자)를 사용자 PATH에 통째로 덮어씀 | 고침 v0.5.1 | 사용자 PATH만 읽어 설치 경로를 덧붙인다 |
| 2 | 삭제할 때 디스크를 다시 읽지 않아 다른 터미널에서 등록한 프로젝트가 사라짐. 반대로 삭제한 프로젝트가 추가 시 되살아남. 쓰기도 원자적이지 않음 | 고침 v0.5.1 | `persist_add` / `persist_remove`가 저장 직전에 다시 읽음. 쓰기는 임시 파일 + rename |
| 3 | 유휴 상태에서도 약 30ms마다 전체 재그리기 | 고침 v0.5.1 | 실행 중인 세션이 있을 때만 주기적으로 그림. v0.5.3부터 측정 결과가 도착할 때(2초마다) 한 번씩 그림 |
| 4 | `canonicalize`가 `\\?\C:\...` 경로를 저장 | 고침 v0.5.1 | `plain_path`로 접두사 제거(UNC는 유지). 이미 저장된 옛 항목은 그대로 남아 있음 → [open-work.md](open-work.md) |

`cmd.exe`는 `\\?\` cwd를 문제없이 받는 것을 직접 확인했다. 그래서 심각도는 낮고, 문제는 `squad list` 출력과 일부 도구에서의 호환성이었다.

## 사용성

| 항목 | 상태 | 비고 |
|---|---|---|
| F1~F12가 세션에 전달되지 않음 | 고침 v0.5.1 | xterm 시퀀스. Shift, Ctrl 조합 포함 |
| `Ctrl+G` 뒤에 다른 키를 누르면 그 키가 매니저 명령으로 실행됨(`Ctrl+G`, `q`가 종료창을 띄움) | 고침 v0.5.1 | 접두사만 취소 |
| 삭제, 추가 때 필터가 조용히 풀림 | 고침 v0.5.1 | 삭제는 필터 유지, 추가는 새 프로젝트가 보이도록 해제 |
| add 폼에서 공백이 든 경로나 따옴표 인자를 쓸 수 없음 | 고침 v0.5.1 | `split_command`가 큰따옴표를 처리 |
| 필터 결과가 0건이면 필터를 다시 열 수 없음 | 고침 v0.5.2 | 키맵 재설계 중 발견 |
| 도움말 팝업이 24줄 터미널에서 마지막 줄이 잘림(높이 50%) | 고침 v0.5.2 | 줄 수에 맞춘 고정 크기 |
| 마우스 이벤트, Shift+Enter 전달 | 보류 | 마우스 캡처 때문에 vim 같은 앱은 마우스를 못 받음 |
| bracketed paste | macOS만 고침 v0.15.14 | Windows 콘솔 API에는 붙여넣기 이벤트가 없어 그대로 둠. macOS(unix)는 켜서 여러 줄 붙여넣기가 한 덩어리로 세션에 들어감 |

## 구조

| 항목 | 상태 |
|---|---|
| `main.rs` 한 파일, `run()` 하나가 약 1000줄. 테스트는 렌더링 보조 함수에 치우치고 키 처리 상태 머신은 미검증 | 보류 |
| 상태를 `String`(`"Running"`, `"Exited (0)"`)으로 들고 `starts_with`로 판별 → `enum Status` 권장 | 보류 |
| `focus`, `sending`, `filtering`, `adding`, `show_help`와 `confirm_*` 불리언 여러 개로 모드를 표현 → `Mode` enum 권장 | 보류 |
| CI, 테스트가 Windows 전용인데 `cfg!(windows)` 분기가 있음 | README에 "Windows only" 명시로 정리 |
